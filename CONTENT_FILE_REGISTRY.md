# Реестр обязательных файлов контента ZachetEnot

Статусы отражают фактическое наличие/готовность на 2026-11-03. Ни один учебный артефакт не объявлен утверждённым без проверки.

|---|---|---|---|---|

| `QUESTION_BANK_MASTER.xlsx` | Редактируемый мастер-банк с ID, навыком A–H, типом задания, содержанием, ключом, объяснением, источником и статусом проверки. | `content/QUESTION_BANK_MASTER.xlsx` | **Не создан; ожидает матрицу и утверждённый контракт.** | `SKILLS_MATRIX_V2.xlsx`, `MVP_CONTENT_SCOPE.md`, `CONTENT_SCHEMA.json`, предметные исходные материалы и проверяющий эксперт. |

## Поток артефактов

`аудит матрицы 2.0 + исходная матрица → SKILLS_MATRIX_V2.xlsx → MVP_CONTENT_SCOPE.md + CONTENT_SCHEMA.json → QUESTION_BANK_MASTER.xlsx → CONTENT_VALIDATION_REPORT.md → версионированный russian_grade3.json → Android asset → сборка и QA`.

`CONTENT_CHANGELOG.md` сопровождает каждое принятое изменение мастер-банка, схемы и экспортированного JSON.

## Критерий статуса «готов»

Ставить статус «готов» только при наличии файла, зафиксированной версии, пройденных зависимых проверок и приёмки. Текущий Android JSON не является проверенной версией только потому, что он лежит в assets. Материалы аудита матрицы 2.0 — ожидаемый вход, а не основание повторять полный аудит учебников.
