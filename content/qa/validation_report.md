# ZachetEnot — проверка контентного пакета

- Создано содержательных вопросов: **138** (без пустых заготовок).
- По направлениям UI: Речь и текст — 26, Предложение — 20, Состав слова — 28, Правописание корней — 24, Имя существительное — 20, Имя прилагательное — 20.
- Каждый вопрос: 4 различных варианта, уникальный ID, однозначно назначенный ключ ответа, объяснение правила в master XLSX, источник (часть, печатная страница, номер упражнения).
- JSON проверен по схеме, соответствующей `ContentParser.kt` текущего репозитория.
- Историческая матрица A–H: 108 ID (91 confirmed согласно прежнему аудиту); невыясненные исходные формулировки не заменялись выдуманными.
- Важное разграничение: автоматическая проверка проверяет структуру и ключи, но не заменяет независимую содержательную приёмку всех созданных вопросов. Новые вопросы требуют такой приёмки перед выпуском детям.
- По частям 3 и 4 учебника содержание не включалось.
