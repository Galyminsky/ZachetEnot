# ZachetEnot Content Factory

Основная база вопросов: `questions/question_bank.xlsx`. Данные для Android (контракт текущего `ContentParser.kt`): `android/russian_grade3.json`. Для проверки источников, навыков и правильных ответов: `questions/questions_review.json`.

Все задания созданы по конкретным материалам частей 1–2 учебника и требуют итогового редакторского утверждения; они не являются цитатами готового банка ответов из учебника. Не заменяйте действующий assets без приёмки и теста на устройстве.
