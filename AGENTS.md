# Постоянные правила проекта

- Перед началом любой задачи прочитай `PROJECT_LOG.md` целиком.
- После завершения каждой задачи, включая задачу «только отчёт», добавь запись в раздел «Журнал» по формату из раздела «Формат записи». При необходимости обнови разделы «Текущее состояние», «Карта проекта», «Принятые решения» и «Открытые вопросы». Запись добавляется до финального отчёта.
- `PROJECT_LOG.md` не добавлять в git. Не выполнять commit/push.
- Выполняй только поставленную задачу. Проблемы вне задания только сообщай, не исправляй.
- Не запускай сборку, тесты и эмулятор, если задание этого прямо не требует. Сборку и тесты запускает владелец в Android Studio.
- Не добавляй зависимости и абстракции без обоснования в задании.
- В поле «Приёмка» каждой новой записи всегда указывай «ожидает». Меняй статус только по прямому указанию в задании.
